# AppTV

Fichiers d'installation d'AppTV. Un compte est nécessaire pour l'utiliser : il n'y a pas d'inscription publique.

Les fichiers sont dans [Releases](../../releases/latest).

## Logiciels inclus

L'installateur Windows contient [mpv](https://github.com/mpv-player/mpv) 0.41.0 (GPL), dont le code source est disponible sur sa page, et [Electron](https://github.com/electron/electron) (MIT).
